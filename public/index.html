地图与漫游设置

NetWalk 把你的下载/上传速率和打字速度，换算成走路或跑步的速度，让一个分身在地图上替你走完这一天。
当前未配置高德 Key，处于演练模式：使用程序生成的虚构城市路网，玩法完整但路名为虚构。 配置高德 Key 后可切换为真实城市路网与真实路名。
请用你自己的手机号申请，不要填别人的 Key。步骤：手机号注册 高德开放平台 → 完成个人实名认证 → 应用管理 → 创建新应用 → 添加 Key → 服务平台务必选「Web 端 (JS API)」（选错会不可用）。
免费额度：个人认证开发者每天 5000 次，够用（本游戏已内置调用量软上限，见下方说明）。
Key 只保存在本机 data/config.json，不会上传，也不会写进分享图或存档码。
在高德控制台与 Key 一起生成、但值不同（不要填成 Key 本身，否则地址解析会一直超时）。留空保持不变；地址解析超时时可点上面「清除安全密钥」试一次——若你的 Key 没开「静态安全密钥」，填了反而会被拒。
⚠ 分享给别人之前：不要把 data/config.json 一起发出去（里面存着你的 Key）。 只发代码目录即可 —— 项目已内置 .gitignore 忽略 data/， 对方打开设置用自己的手机号申请 Key，或者什么都不填直接玩演练模式。
